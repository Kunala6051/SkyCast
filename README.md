# 🌤️ SkyCast - Smart Weather Dashboard

SkyCast is a responsive weather dashboard built using **HTML, CSS, and Vanilla JavaScript**. It provides real-time weather information, a 3-day weather forecast, and a simple JSON-based login system. The application fetches live weather data using the **WeatherAPI** and offers a clean, user-friendly interface.

---

## 🚀 Features

- 🔐 User Login Authentication using `users.json`
- 🌍 Live Weather Information
- 📅 3-Day Weather Forecast
- 🔎 Search Weather by City
- 🕒 Displays Local Time
- 💧 Humidity & Wind Speed
- 🌡️ Current Temperature
- 🌤️ Weather Condition Icons
- ⭐ Recent Searches using Local Storage
- 📱 Fully Responsive Design
- ⚡ Fetch API for asynchronous data retrieval

## 🔑 Weather API Setup

1. Visit **https://www.weatherapi.com/**
2. Create a free account.
3. Generate your API Key.
4. Open `dashboard.js`
5. Replace:

```javascript
const API_KEY = "YOUR_WEATHERAPI_KEY";
```

with your own API key.

---

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/Kunala6051/SkyCast.git
```

2. Open the project folder.

3. Replace the WeatherAPI key in `dashboard.js`.

4. Open **index.html** in your browser.
